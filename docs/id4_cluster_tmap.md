# ID.4 계기판 티맵 표시 — 실차 스캔 결과와 배선 기록

VW ID.4(MEB) 순정 계기판에 티맵(carrot SDI/ATC) 정보를 표시하는 기능의 근거 자료.
계기판이 받아주는 CAN 표시 신호를 실차에서 전수 스캔해서 확정한 값들이며,
구현은 `opendbc_repo/opendbc/car/volkswagen/carcontroller.py`(HUD 이벤트 매핑)와
`mebcan.py`(`MEB_ACC_01` 생성)에 있다. ID.4/MEB 선택 시 자동 적용, 별도 토글 없음.

## 스캔 방법

carrot 설정에 테스트 탭(TEST)을 만들어 `MEB_ACC_01`(=if2 ACC_19, 0x300)과 `LDW_02`의
표시 신호 26종을 파라미터로 실시간 오버라이드(`ClusterTest=1`, 1Hz 갱신)하면서
계기판 반응을 사진으로 채증했다. 스캔 도구 배선은 carrot-wip-tj-test 브랜치에만 있다
(carcontroller의 `CLUSTER_TEST_*` 테이블 + mebcan `test_overrides` 인자).
제어(가감속/조향) 신호는 스캔 대상에서 제외.

## 확정된 매핑 (ID.4 MK1, 한국 사양, 실차 채증)

### ACC_Events (큰 배너: 그림 + 문구 + 목표속도)

| 값 | 계기판 표시 |
|---|---|
| 0 | 없음 |
| 1, 2 | 미확정 (스캔에서 반응 확인 못함) |
| 3 | 정차 대기 (순정 로직 그대로 사용) |
| 4 | 제한속도 표지판 + "전방" 문구 |
| 5 | 제한속도 표지판 + "인식됨" 문구 |
| 6 | 커브 (S자) |
| 7 | 커브 오른쪽 |
| 8 | 커브 왼쪽 |
| 9 | 교차로 |
| 10 | 로터리(회전교차로) |
| 11 | 고속도로 출구 |
| 12 | 정체 |
| 13 | 병목 |
| 14 | 내리막 |
| 15 | 오르막 |

### Lead_Brightness (주행 그래픽 옆 미니 상태 아이콘)

이름과 달리 밝기가 아니라 **아이콘 선택기**다. 4비트.

| 값 | 표시 |
|---|---|
| 0 | 없음 (앞차 회색) |
| 3 | 기본값 — ACC 활성 시 앞차 하이라이트(흰색) |
| 4 | km/h 뱃지 |
| 5~14 | 이벤트 N+1과 같은 그림의 미니 아이콘 (5=커브S … 14=오르막) |
| 15 | 꽃길(에코/경치 계열) 아이콘 |

**함정: 커브 좌우가 배너와 거울상.** 배너는 7=우/8=좌인데 미니 아이콘은 7=우/6=좌.
그래서 커브만 특례 매핑이 필요하다 (carcontroller에 구현).

### 미사용/봉인 판정

| 신호 | 판정 |
|---|---|
| `ACC_Texte_Primaeranz_02` / `Zusatzanz_02` | ID.4에서 미표시 (MQB 유산으로 추정) |
| `ACC_rel_Objekt_*` (RelObj) | 한국 사양에서 완전 미사용 — 옆차 아이콘 아님, 하이라이트 복구도 아님 |
| Unknown_01/02/06~09 비트 | **ACC 오류 계열 경고 메시지** — 건드리지 말 것 (봉인) |
| PSD (순정 지도 데이터) | 순정 내비 없는 차량은 빈 껍데기 → 오르막/내리막(14/15) 자동 표시는 보류 |

## 현재 배선 설계

우선순위: 단속카메라 > 커브 > 교차로 > 출구 > 로터리 > 병목 > 정차대기.

- **단속카메라/구간단속** (`naviSpeedLimit>0`): 이벤트 4 (표지판+"전방") — 지날 때까지 배너 유지
- **내비 이벤트 (커브/교차로/출구/로터리/병목)**: 새로 뜰 때만 큰 배너 약 1.2초
  (16Hz×20프레임) → 이후 미니 아이콘으로 전환해 유지. 커브 방향은 `vTurnSpeed` 부호
  (양수=우, 음수=좌 — 실주행 검증).
- **도로 제한속도 제어 중** (`naviEventType==8`, AutoRoadSpeedLimit 연동): 제한값이
  실제로 바뀔 때만 배너(이벤트 5, "인식됨") 1.2초 → 이후 km/h 뱃지(아이콘 4).
- **앞차 하이라이트와의 조정**: `Lead_Brightness`가 단일 필드라 아이콘과 앞차색을
  동시에 못 쓴다. 색 = "현재 속도의 지배자" 원칙 — 앞차가 속도를 제한 중이면
  (`hudControl.leadLimiting`, 플래너 xState==lead) 앞차 하이라이트 우선, 그 외에는
  km/h 뱃지. 정체에서 지배자가 수초마다 왕복하며 깜빡이는 것을 막기 위해 약 2초
  (32프레임@16Hz) 디바운스.
- 정체(12) 표시는 오작동이 잦아 배선에서 제외했다.

## 남은 것

- 이벤트 1, 2 정체 (계기판 반응 미확인)
- `ClusterEventSpeed`(이벤트 목표속도)와 티맵 통과속도 연동은 커브/교차로/출구/로터리에 적용됨
